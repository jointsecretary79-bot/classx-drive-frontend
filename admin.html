Post a Drive update

Adds an entry to the "Daily updates log" on index.html, and optionally to the scrolling yellow ticker. Can also attach a file, which gets uploaded straight into the GitHub repo.

GitHub connection settings

Create this at github.com → Settings → Developer settings → Fine-grained tokens. Scope it to only this one repo, permission "Contents: Read and write". Don't share this token — anyone with it can edit the site.

Select as many files as you like. On the app, photos show as a tappable, zoomable gallery; PDFs show as a separate "Open PDF" button — they never get mixed up. All files are stamped with today's date and time. If you don't set a link above, the update's link points to the first file.

Tip: an update needs at least one of "ticker" or "list" checked, or it won't be visible anywhere. Everything here — including which folders it's filed under — can be changed later in "Manage posted updates" below, without deleting and re-posting.
